# 🤖 Telegram Reminder Bot

Бот для создания напоминаний с поддержкой часовых поясов и GPS.

## 🚀 Деплой на Railway

1. **Запушьте код** в GitHub-репозиторий
2. **Откройте [Railway.app](https://railway.app)** → `New Project` → `Deploy from GitHub repo`
3. **Выберите ваш репозиторий**
4. **Добавьте переменную окружения**:
   - Перейдите в `Variables`
   - Нажмите `+ New Variable`
   - Добавьте `BOT_TOKEN` с вашим токеном от @BotFather
5. **Готово!** Бот автоматически запустится

## 📋 Команды

- `/start` - Приветствие
- `/add` - Создать напоминание
- `/myevents` - Мои мероприятия
- `/settz` - Изменить часовой пояс
- `/help` - Помощь

## 🔧 Функции

- ⏰ Напоминания с указанием времени
- 🔄 Повтор: ежедневно/еженедельно/ежемесячно
- 🌍 Автоматическое определение часового пояса через GPS
- 📊 Просмотр всех событий
- 💾 SQLite база данных
