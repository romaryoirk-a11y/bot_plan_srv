# 🤖 Telegram Reminder Bot

Умный Telegram-бот для создания напоминаний с поддержкой часовых поясов, GPS-определения локации и гибкого повторения событий.

## ✨ Возможности
- ⏰ Создание напоминаний с указанием даты и времени
- 🔄 Повтор: ежедневно, еженедельно, ежемесячно или без повтора
- 🌍 Автоматическое определение часового пояса через GPS
- 📊 Удобный просмотр списка мероприятий (`/myevents`)
- ⚡ Оптимизирован для серверных деплоев (Vercel, Railway, VPS)

## 🛠 Стек технологий
- **Python 3.10+**
- `python-telegram-bot` ≥20.0 (Webhook/Polling)
- `apscheduler` (планировщик задач)
- `pytz` & `timezonefinder` (часовые пояса)
- `starlette` (ASGI-сервер для Vercel)
- `SQLite3` (локальная БД)
